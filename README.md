# Toronto Parking Map

Toronto parking bylaw data pipeline and interactive map — from city open data to map-ready GeoJSON and a web UI.

| Directory | Description |
|-----------|-------------|
| [`pipeline/`](pipeline/) | Python ETL: parse bylaw text, resolve streets against Toronto Centreline, emit GeoJSON |
| [`web/`](web/) | React + TypeScript map app |

**Documentation:** [pipeline/docs/README.md](pipeline/docs/README.md) (pipeline deep-dive)
